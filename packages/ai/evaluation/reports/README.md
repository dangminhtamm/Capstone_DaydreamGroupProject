# Memory Evaluation Reports

This directory is reserved for valid memory quality reports generated by:

```bash
pnpm eval:memory-report
```

The stable demo artifacts are:

- `memory-evaluation-latest-valid.md`
- `memory-evaluation-latest-valid.json`

Runtime-invalid diagnostic reports are archived under `invalid/` only when
`MEMORY_REPORT_WRITE_INVALID=1` is set.
