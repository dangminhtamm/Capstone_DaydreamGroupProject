The Second Brain: A High-Performance Infinite Memory & Hierarchical Reflection Engine 
 
"Context & Vision Tuturuuu is building an all-in-one workspace to help users “Work Smarter, 
Live Better.” As a member of the Google for Startups program, we are exploring next-
generation AI agents that can act as a “second brain” with near-infinite memory, capable of 
organizing a user’s entire digital life. Objectives The goal is to build a high-performance backend 
engine utilizing Google Gemini models (via the Tuturuuu AI Gateway) and a high-speed backend 
(Rust/Go/Python/NodeJS). This will be demonstrated through a flagship prototype: A Smart 
Personal Diary. This application will not only store daily entries but actively organize them into 
meaningful long-term insights. Core Challenge The system must ingest unstructured data (text 
entries, media, documents) and automatically generate hierarchical summaries, aggregating 
Daily Entries → Weekly Summaries → Monthly Reviews → Yearly Retrospectives, to facilitate 
deep user reflection without manual effort." 
 
 "1. MVP Prototype (Smart Diary App): A fully functional web application where users can log 
daily activities. The system must autonomously process these logs to create “living” biographies 
of the user. 2. Infinite Memory Engine: A backend service that retains “infinite” context, 
allowing users to query past events naturally (e.g., “What was the feedback I received on my 
project last March?”). 3. Hierarchical Summarization Pipeline: An AI agent workflow that 
periodically aggregates data: •Level 1: Synthesizing daily scattered notes into a cohesive Daily 
Log. •Level 2: Analyzing 7 days of logs to generate a Weekly Review. •Level 3: Compiling 
Monthly and Yearly Retrospectives for user reflection. 4. Google Ecosystem Integration: 
Implementation of connectors for Gmail, Google Calendar, and Google Contacts to enrich the 
diary with real-world context (e.g., auto-linking a meeting from Calendar to a diary entry). 5. 
Universal Data Ingestion: Capability to parse and structure blobs (PDF, Images, Audio) attached 
to diary entries." 
 
"•Retrieval Latency: Search and memory recall operations must complete in ≤ 500ms to ensure 
a seamless “thought-speed” experience. •Summarization Quality: Generated Weekly/Monthly 
summaries must accurately reflect >90% of key events recorded in daily entries (verified via 
user testing). •Integration Reliability: Successful, error-free syncing of data from at least one 
Google service (Gmail or Calendar) during the final demo. •Scalability: The architecture must 
handle a “Yearly” view (365+ nodes of complex data) without UI lag or retrieval timeout." 
 
"Required Tech Stack: •Frontend: Next.js, TypeScript, Tailwind CSS. •Database: Supabase 
(PostgreSQL/pgvector). •Backend: Choice of Rust (preferred for performance), GoLang, Node.js, 
or Python. •AI Integration: Tuturuuu SDK (TypeScript) interacting with Google Gemini, Vercel AI 
SDK. Professional Skills: •System Design: Ability to design hierarchical data structures for long-
term memory. •API Integration: Experience with OAuth and third-party APIs (specifically Google 
Workspace APIs). •Creative Problem Solving: Ability to design a “Retrospective” UX that 
encourages user engagement."
